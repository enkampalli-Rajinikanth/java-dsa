# Java DSA 🚀

A collection of Data Structures and Algorithms problems
implemented in Java for coding interview preparation.

## 📚 Topics

- Arrays
- Strings
- HashMap & HashSet
- Prefix Sum
- Two Pointers
- Sliding Window
- Stack
- Queue
- Linked List
- Trees
- Recursion
- Sorting

## ⭐ Important Problems

### Arrays
- Two Sum
- Maximum Subarray
- Majority Element
- Move Zeros
- Missing Number

### Strings
- Reverse String
- Palindrome
- Anagram
- Longest Substring Without Repeating Characters

### Linked List
- Reverse Linked List
- Find Middle of Linked List
- Detect Cycle
- Merge Two Sorted Linked Lists
- Nth Node From End

### Stack
- Valid Parentheses
- Next Greater Element
- Stock Span

## 🎯 Goal

To improve problem-solving skills and prepare for
Java coding interviews.
